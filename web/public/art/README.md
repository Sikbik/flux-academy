# Art, social cards and icons: provenance and use

Everything the asset pipeline puts in `web/public/` besides the official Flux marks in
`web/public/brand/` (which are never edited here). The typed manifest for all of it is
`web/src/content/art.ts`, which is generated: do not edit it by hand. This file is generated too
(`node web/scripts/optimize-art.mjs`).

## Licence note

The files in `web/public/art/` are original generated artwork for this project. The Flux marks and
lockups come unmodified from the official brand kit; no generated image reproduces the Flux symbol or any
text.

## Generated art (`web/public/art/`)

Each piece was generated by the Codex CLI image generation tool through `scripts/imagegen.mjs`, using the
prompt recorded under the piece's id in [`assets-src/PROMPTS.md`](../../../assets-src/PROMPTS.md) (with what
each take taught us), then post-processed by `web/scripts/optimize-art.mjs`: black floor crushed to 0,
auto-fit (the lit subject is measured and re-framed so a group shares one scale and one centring), a smooth
edge mask so the outer ring is exactly `#000`, WebP at quality 86 (lower only if a budget demands it) and
AVIF where it is at least 15 percent smaller at equal DSSIM. Originals are in `assets-src/raw/` and are
not committed.

Budget: each file under 120 KB (sprites under 60 KB), total art about 1.4 MB. Now: 36 pieces,
1156 KB as WebP, 831 KB when AVIF is served where present.

### How to composite each group

| Group | Blend | How |
| --- | --- | --- |
| Tracks, modules, labs, medals (square) | `screen` | Light on pure black. Draw over any dark surface (`--ink-0` to `--ink-3`) with `mix-blend-mode: screen`; never on a light surface. No box shows, and the glow is meant to spill past the layout box. Draw at half the file size or less for a crisp 2x. |
| Tracks | `screen` | The three share one baseline (the base sits at 92 percent of the frame height) and rise cumulus 55, nimbus 70, stratus 84 percent, so a row of the three reads short, mid, tall with no layout code. Tier colours belong to tiers and tracks only. |
| Modules, labs | `screen` | Subject centred and sized to about 74 percent of the frame (the maps and pillar fields a little larger). `box` in the manifest is the lit area. |
| Medals | `screen` | One hexagonal body, one emblem each. Flux blue for the nine achievements, tier colour plus a ring of studs for the three ranks. For a locked medal dim it in CSS (`filter: grayscale(1) brightness(0.35)` or opacity 0.3); do not ship a second file. |
| `bg-bench` | `screen` | 16:9 plate: a hazy field of pillars in the middle band, the upper 40 percent and the left, right and bottom edges are black. Use as a full-bleed cover behind the hero when WebGL is off or on small screens; put a scrim (a vertical gradient to `--ink-0`) behind text. The one piece that carries all three tier colours, because it depicts the tiers. |
| `sprite-bokeh` | alpha | 256x256 soft hexagonal highlight with real transparency. Scatter as quads or point sprites, additive, tinted by multiplying the colour. |
| `sprite-streak` | alpha | 512x64 anamorphic streak with real transparency. Stretch horizontally; additive. |
| `sprite-dirt` | additive | 960x640 grayscale lens dirt on pure black, **no alpha**. A post-pass texture: add it, scaled by the bloom or by a gentle brightness curve. The dust runs to the edges on purpose. |
| `certificate-backdrop` | `normal` | 3:2 opaque plate. Draw it first on the certificate canvas (scale to the canvas), then the text. The clear panel is about x 0.07 to 0.93, y 0.17 to 0.84; keep text inside x 0.12 to 0.88, y 0.22 to 0.80. |

For the sprites the manifest says which kind each is: `sprite: 'alpha'` (real transparency) or
`sprite: 'additive'` (light on black; screen or additive blending only).

```html
<picture>
  <source srcset="/art/track-cumulus.avif" type="image/avif" />
  <img src="/art/track-cumulus.webp" width="320" height="320" alt="" style="mix-blend-mode: screen" />
</picture>
```

**Alt text.** `alt` describes the artwork, for the places where it stands alone. Where a piece sits next
to its own visible title (a track card, a medal with its name) pass `alt=""` so a screen reader does not
read the same thing twice. Atmosphere and backdrops are `decorative: true` with an empty `alt`.

## Regenerate

From the repository root (the machine needs the Codex CLI, ImageMagick, `avifenc`, `rsvg-convert` and
the system Chromium; no API key is read, Codex is already logged in):

```sh
# 1. raw art, about 35 s each, 4 at a time. Missing pieces only; --force redoes (the old take is kept in
#    assets-src/raw/_prev), --only picks. Medals after the first use medal-first-light as a reference, so
#    generate that one first on a fresh clone.
node web/scripts/generate-art.mjs --only medal-first-light
node web/scripts/generate-art.mjs
node web/scripts/generate-art.mjs --force --only track-nimbus

# 2. crop, auto-fit, mask, encode, rewrite assets-src/art-manifest.json, art.ts and this README
node web/scripts/optimize-art.mjs
node web/scripts/optimize-art.mjs --sheet      # contact sheets in assets-src/_work (git-ignored)

# 3. social cards and icons
node web/scripts/build-og.mjs
node web/scripts/build-icons.mjs

# docs: assets-src/PROMPTS.md is generated from assets-src/art-spec.mjs
node web/scripts/generate-art.mjs --prompts-md
```

To change a prompt, edit `assets-src/art-spec.mjs`, regenerate that piece with `--force --only <id>`, look
at it, then run step 2. The test `web/src/content/art.test.ts` checks every file exists, matches its stated
size and is inside the budget.
